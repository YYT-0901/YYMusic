# YYMusic API 接口文档

**版本**: 1.0 **说明**: 本文档包含了 YYMusic 平台的管理后台与 Web 前端的所有接口定义。 **通用返回格式**: 所有接口（除文件下载/回调外）统一返回 `ResponseVO` 对象。

```json
{
  "status": "success/error",
  "code": 200,
  "info": "描述信息",
  "data": { ... }
}
```

---

## 一、 Web端接口

**Base URL**: `/api` (假设 Nginx 转发配置，实际以部署为准)

### 1. 账号管理

#### 1.1 获取图形验证码

- **URL**: `/account/checkCode`
- **Method**: `GET` / `POST`
- **描述**: 获取图形验证码图片及对应的 Key。

| **参数名** | **类型** | **必填** | **说明** |
| ---------- | -------- | -------- | -------- |
| 无         | -        | -        | -        |

> **返回示例**:
>  
> ```
>   {
>     "status": "success",
>     "data": {
>        "checkCodeKey": "xyz123...",
>        "checkCode": "data:image/png;base64,iVBORw0KG..."
>     }
> }
> ```

#### 1.2 用户注册

- **URL**: `/account/register`
- **Method**: `POST`
- **描述**: 用户注册接口。

| **参数名**   | **类型** | **必填** | **说明**          |
| ------------ | -------- | -------- | ----------------- |
| checkCodeKey | String   | 是       | 验证码 Key        |
| checkCode    | String   | 是       | 验证码内容        |
| email        | String   | 是       | 邮箱 (最大50字符) |
| password     | String   | 是       | 密码 (8-18位)     |
| nickName     | String   | 是       | 昵称 (最大20字符) |

#### 1.3 用户登录

- **URL**: `/account/login`
- **Method**: `POST`
- **描述**: 用户登录，返回 Token。

| **参数名**   | **类型** | **必填** | **说明**   |
| ------------ | -------- | -------- | ---------- |
| checkCodeKey | String   | 是       | 验证码 Key |
| checkCode    | String   | 是       | 验证码内容 |
| email        | String   | 是       | 邮箱       |
| password     | String   | 是       | 密码       |

> **返回示例**:
>
> ```json
> {
>     "status": "success",
>     "code": 200,
>     "info": "请求成功",
>     "data": {
>         "userId": "282272802761",
>         "nickName": "新世界的神",
>         "token": "4ea72bd381e607600b82c6d48b41a56e",
>         "avatar": "avatar/282272802761.png",
>         "integral": 5000
>     }
> }
> ```

#### 1.4 获取/刷新登录用户信息

- **URL**: `/account/getLoginInfo`
- **Method**: `POST`
- **描述**: 根据 Header 中的 Token 获取最新用户信息（含积分）。

| **参数名** | **类型** | **必填** | **说明**               |
| ---------- | -------- | -------- | ---------------------- |
| 无         | -        | -        | 需在 Header 携带 Token |

> **返回示例**: 同登录接口返回结构。

#### 1.5 修改密码

- **URL**: `/account/updatePassword`
- **Method**: `POST`
- **描述**: 修改当前登录用户的密码。

| **参数名**  | **类型** | **必填** | **说明** |
| ----------- | -------- | -------- | -------- |
| oldPassword | String   | 是       | 旧密码   |
| newPassword | String   | 是       | 新密码   |

#### 1.6 修改用户信息

- **URL**: `/account/updateUserInfo`
- **Method**: `POST`
- **描述**: 修改昵称或头像。

| **参数名** | **类型** | **必填** | **说明**                 |
| ---------- | -------- | -------- | ------------------------ |
| nickName   | String   | 是       | 昵称                     |
| avatar     | File     | 否       | 头像文件 (MultipartFile) |

> 返回示例:
>
> ```json
> {
>     "status": "success",
>     "code": 200,
>     "info": "请求成功",
>     "data": {
>         "userId": "282272802761",
>         "nickName": "新世界的神",
>         "token": "4ea72bd381e607600b82c6d48b41a56e",
>         "avatar": "avatar/282272802761.png",
>         "integral": 5000
>     }
> }
> ```

#### 1.7 退出登录ge't

- **URL**: `/account/logout`
- **Method**: `POST` (或 GET)
- **描述**: 注销当前登录状态。

| **参数名** | **类型** | **必填** | **说明**                 |
| ---------- | -------- | -------- | ------------------------ |
| 无         | -        | -        | 需在 Header 中携带 Token |

### 3. 我的音乐与创作

#### 3.1 创建音乐 (AI生成)

- **URL**: `/my/createMusic`
- **Method**: `POST`
- **描述**: 提交参数开始生成音乐。

| **参数名**   | **类型** | **必填** | **说明**                    |
| ------------ | -------- | -------- | --------------------------- |
| prompt       | String   | 是       | 提示词 (Max 2000)           |
| lyrics       | String   | 否       | 歌词 (Max 1500)             |
| musicType    | Integer  | 是       | 音乐类型 (0:歌曲, 1:纯音乐) |
| model        | String   | 是       | 使用的模型                  |
| musicGener   | String   | 否       | 音乐流派 (Max 200)          |
| musicEmotion | String   | 否       | 情绪 (Max 150)              |
| musicSex     | String   | 否       | 人声性别                    |
| modeType     | Integer  | 是       | 模式类型                    |

> **返回示例**:
>
> ```
> {
>   "status": "success",
>   "data": ["M_ID_1", "M_ID_2"]  // 返回生成的音乐ID列表
> }
> ```

- **URL**: `/account/login`
- **Method**: `POST`
- **描述**: 管理员登录接口，返回访问 Token。

| **参数名**   | **类型** | **必填** | **说明**               |
| ------------ | -------- | -------- | ---------------------- |

| checkCode    | String   | 是       | 验证码内容             |
| account      | String   | 是       | 管理员账号             |
| password     | String   | 是       | 密码 (通常为MD5加密后) |

> **返回示例**
>
> ```
> {
>   "status": "success",
