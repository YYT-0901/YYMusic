YYMusic 后端事实知识库

适用范围
- 本知识库基于当前后端源码整理，面向平台智能客服、产品问答与创作辅助场景。
- 当知识库描述与实时接口返回、系统字典或数据库配置冲突时，以实时数据为准。
- 未在源码中发现的功能，不应被当作已支持能力。

项目定位
- YYMusic 是一个 AI 音乐生成与商业化运营平台后端。
- 系统同时覆盖前台用户端、后台管理端、音乐生成回调、支付回调、文件资源访问与 AI 智能体能力。
- 项目为 Maven 多模块结构，核心模块包括 `yymusic-web`、`yymusic-common`、`yymusic-admin`。

核心业务模块
- 音乐创作：提交歌曲或纯音乐生成任务，扣减积分，创建本地创作记录与音乐记录，等待回调或轮询更新结果。
- 音乐社区：推荐音乐、最新音乐、热门音乐、音乐详情、播放计数、点赞、公开用户主页。
- 个人中心：我的音乐、创作中音乐查询、积分流水、上传封面、改标题、删除作品。
- 商业化支付：在售积分商品、微信支付、支付宝支付、支付码支付、支付状态轮询、异步回调。
- AI 能力：文本润色与歌词生成流式智能体，带 RAG 与函数工具的智能客服。
- 文件服务：头像、商品封面、音乐封面、音频文件读取；支持 Range 请求。
- 后台运营：用户管理、商品管理、支付码管理、订单管理、音乐推荐管理、系统字典管理。

一、账号与登录能力

账号接口
- `/account/checkCode`：获取图形验证码和验证码 key。
- `/account/register`：用户注册，需要邮箱、密码、昵称、验证码。
- `/account/login`：用户登录，需要邮箱、密码、验证码。
- `/account/getLoginInfo`：读取当前登录用户信息。
- `/account/logout`：退出登录。
- `/account/updatePassword`：登录后修改密码。
- `/account/updateUserInfo`：登录后修改昵称和头像。

账号规则
- 登录态依赖请求头 `token`。
- 验证码与登录 token 均存储在 Redis。
- 用户头像支持上传。
- 源码中未发现“邮箱验证码登录”“短信登录”“第三方 OAuth 登录”“在线找回密码”接口。

二、音乐创作能力

创作入口
- `/my/createMusic`：提交音乐创作请求。
- 返回值为音乐 ID 列表，而不是单个音乐 ID。

创作类型
- `musicType=0`：歌曲。
- `musicType=1`：纯音乐。

创作模式
- `modeType=0`：简单模式。
- `modeType=1`：高级模式。

创作参数
- 必填核心参数：`prompt`、`musicType`、`modeType`。
- 可选参数：`lyrics`、`musicGener`、`musicEmotion`、`musicSex`、`musicChord`、`musicTone`、`model`。
- 歌曲场景可带歌词；纯音乐场景通常不需要歌词。
- 高级模式下，音乐设置会被拼接进 prompt 参与生成。

创作业务规则
- 系统会先校验音乐类型和模型是否合法。
- 模型合法性来自系统字典与模型枚举，不是任意字符串。
- 创建前会先扣减积分。
- 若音乐生成失败，系统会退还对应积分。
- 创建成功后会落库 `music_creation` 与 `music_info` 数据。
- 如果开启自动轮询，任务会进入 Redis 队列等待状态检查；否则可通过回调更新状态。

音乐状态
- `0`：生成中。
- `1`：生成完成。
- `2`：生成失败。

创作相关用户接口
- `/my/loadMyMusic`：分页查询用户自己的音乐列表。
- `/my/loadCreatingMusic`：按音乐 ID 列表查询创作中任务状态。
- `/my/uploadMusicCover`：上传音乐封面。
- `/my/delMusic`：删除自己创建的音乐。
- `/my/changeMusicTitle`：修改自己创建的音乐标题。
- `/music/getCreation`：查询某次创作的原始创作详情，可用于复用参数或二次创作。

系统字典与创作选项
- `/my/loadSysDict` 可读取系统字典缓存。
- 音乐模型、曲风、情绪、人声、提示词模板等配置由系统字典维护。
- 这些配置属于可运营数据，不应在知识库中被写死为永远不变。

三、公开音乐与社区能力

公开音乐接口
- `/music/loadCommendMusic`：获取推荐音乐列表。
- `/music/loadLatestMusic`：获取音乐列表，支持最新排序或热门排序。
- `/music/musicDetail`：获取音乐详情。
- `/music/updatePlayCount`：更新播放次数。
- `/music/doGood`：登录后点赞音乐。

排序规则
- `sortType=1`：最新。
- `sortType=0`：热门。

公开音乐规则
- 公开列表主要展示已生成成功的音乐。
- 推荐音乐与普通广场音乐是两类列表。
- 点赞需要登录。

用户公开主页接口
- `/user/getUserInfo`：获取指定用户的公开信息、作品数、获赞数。
- `/user/loadUserMusic`：分页查询指定用户已生成完成的音乐列表。

四、积分、商品与支付能力

商品接口
- `/buy/loadProduct`：获取当前在售积分商品列表。

支付类型
- `0`：支付码支付。
- `1`：微信支付。
- `2`：支付宝支付。

订单状态
- `-1`：超时订单。
- `0`：待支付。
- `1`：已支付。

用户支付接口
- `/buy/getPayInfo`：获取支付信息，返回订单号与支付地址。
- `/buy/getPayInfoAlipay`：获取支付宝表单。
- `/buy/checkPayOrder`：基于 Redis 判断订单是否支付成功。
- `/buy/havePay`：数据库兜底校验订单是否支付成功。
- `/buy/buyByPayCode`：通过支付码购买商品。

支付业务规则
- 商品必须处于在售状态才能购买。
- 支付成功后，用户积分会增加。
- 系统存在支付超时处理逻辑。
- 支付完成后会写入 Redis 标记，前端可以轮询快速确认。
- 微信与支付宝均存在异步回调入口。

积分流水类型
- `0`：创作音乐失败退回。
- `1`：创作音乐消耗。
- `2`：充值。
- `3`：管理员赠送。
- `4`：管理员扣减。

个人积分接口
- `/my/integralRecords`：分页查询当前用户积分流水。

五、AI 智能体能力

文本智能体
- `/agent/aiGen`：流式文本智能体接口。
- 当前智能体类型：
- `type=0`：文本润色。
- `type=1`：歌词生成。

智能客服接口
- `/ai/chat`
- `/ai/chat/{provider}`
- `/ai/chatStream`
- `/ai/chatStream/{provider}`

智能客服特征
- 支持普通返回与流式返回。
- 支持按 provider 显式切换模型通道。
- 当前后端支持 `openai` 与 `ollama` 两类 provider。
- 智能客服结合 RAG 知识检索和函数工具。

智能客服工具能力
- 查询创作选项：`queryMusicCreationOptionsTool`
- 提交音乐生成：`generateMusicTool`
- 查询公开音乐：`queryMusicTool`
- 查询在售套餐：`queryPackagesTool`
- 查询当前登录用户音乐：`queryUserMusicTool`

智能客服工具规则概览
- 与当前登录用户相关的查询或操作，不需要模型自行伪造 `userId`。
- 公开音乐查询支持 `DETAIL`、`LATEST`、`HOT`、`RECOMMEND`。
- 用户音乐查询支持 `MY_CREATED`、`MY_LIKED`、`CREATING`。
- 创作选项推荐应优先依赖工具或系统字典，不应硬编码。

六、文件与资源能力

文件接口
- `/file/getResource`：按文件路径读取资源。

文件能力
- 支持图片、音频等资源读取。
- 支持 HTTP Range 请求，适合音频断点读取。
- 支持路径合法性校验，避免目录穿越。

存储后端
- 本地磁盘。
- MinIO。
- FTP 远程存储。

常见文件场景
- 用户头像。
- 商品封面。
- 音乐封面。
- 音频文件。

七、后台管理能力

后台存在独立管理端模块，包含以下能力
- 管理员登录与退出。
- 用户列表、启用/禁用用户、增减积分。
- 音乐列表管理、推荐状态调整。
- 商品管理、排序调整、商品删除。
- 支付码生成与删除。
- 订单列表查询。
- 系统字典维护。

后台管理相关事实
- 后台系统字典是前台创作配置的重要来源。
- 推荐音乐位由后台控制。
- 支付码可按金额直接创建，也可按商品创建。

八、关键业务边界

可以明确认为已支持的能力
- 注册、登录、登出、修改密码、修改昵称头像。
- 歌曲与纯音乐生成。
- 推荐、最新、热门音乐展示。
- 个人作品管理。
- 积分商品购买。
- 微信、支付宝、支付码支付。
- AI 文本润色、歌词生成、智能客服问答。
- 本地/MinIO/FTP 三种文件存储模式。

源码中未明确发现的能力
- 订阅制会员体系。
- 在线找回密码。
- 短信登录。
- 第三方社交账号登录。
- 用户侧订单取消接口。
- 用户侧批量管理作品接口。
- 独立的“收藏夹”概念；当前更明确的是点赞行为。

九、回答项目介绍时的推荐表述

推荐使用的项目描述
- YYMusic 是一个面向音乐生成场景的 AI 创作与商业化平台后端。
- 平台围绕“创作、社区、积分、支付、AI 辅助、后台运营”六条主线组织能力。
- 前台支持用户创作歌曲或纯音乐、管理个人作品、浏览社区内容并完成积分充值。
- 后台支持商品、字典、支付码、订单、用户与推荐内容运营。

不推荐使用的表述
- 不要把未发现的功能说成已经支持。
- 不要把系统字典中的可运营项描述成永久固定配置。
- 不要把单一 AI 模型或单一支付渠道说成唯一方案。
