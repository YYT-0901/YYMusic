#### 1. WebSocket

- URL： `/ws?client_id={xxx}`
- 描述: 建立长连接以便回调接受生成结果

| **参数名**  | **类型** | **必填** | **说明**                                   |
| :---------- | :------- | :------- | :----------------------------------------- |
| `client_id` | string   | 是       | 由客户端生成的任务ID，用于标记任务发起者。 |

---

#### 2. 下发工作流任务 (POST /prompt)

- **URL**: `/prompt`
- **Method**: `POST`
- **描述**: 用于下发一个新的工作流生成任务。

| **参数名**  | **类型** | **必填** | **说明**                                                     |
| :---------- | :------- | :------- | :----------------------------------------------------------- |
| `client_id` | string   | 是       | 由客户端生成的任务ID，用于标记任务发起者。                   |
| `prompt`    | json     | 是       | 工作流参数，需从ComfyUI编辑器中使用 `Save (API Format)` 功能获取。 |

> **返回示例**:
>
> ```
> {
>   "prompt_id": "0ff43e96-d290-4e56-91c6-c0d3e14878b3",
>   "number": 4,
>   "node_errors": {}
> }
> ```

------

#### 3. 获取任务历史与输出 (GET /history/{prompt_id})

- **URL**: `/history/{prompt_id}`
- **Method**: `GET`
- **描述**: 根据任务ID (`prompt_id`) 查询任务的执行历史及生成的图片等信息。

| **参数名**  | **类型** | **必填** | **说明**                                                     |
| :---------- | :------- | :------- | :----------------------------------------------------------- |
| `prompt_id` | string   | 是       | 任务ID，从 `POST /prompt` 接口的返回中获取。此参数需放在URL路径中。 |

> **返回示例** (已简略):
>
> ```
> {
>   "0ff43e96-d290-4e56-91c6-c0d3e14878b0": {
>     "outputs": {
>       "163": {
>         "images": [
>           {
>             "filename": "ComfyUI_00079_.png",
>             "subfolder": "",
>             "type": "output"
>           }
>         ]
>       }
>     },
>     "status": { ... },
>     ...
>   }
> }
> ```

------

#### 4. 在线预览图片 (GET /view)

- **URL**: `/view`
- **Method**: `GET`
- **描述**: 用于在线预览或获取由ComfyUI生成的图片。

| **参数名**  | **类型** | **必填** | **说明**                                                     |
| :---------- | :------- | :------- | :----------------------------------------------------------- |
| `filename`  | string   | 是       | 图片的文件名，例如 `ComfyUI_00079_.png`。                    |
| `type`      | string   | 否       | 图片存放的文件夹类型。`input` 为上传的图片，`output` 为生成的图片。 |
| `subfolder` | string   | 否       | 图片所在的子文件夹路径（如果没有，可不填）。                 |
| `preview`   | string   | 否       | 预览参数。                                                   |
| `channel`   | string   | 否       | 通道参数。                                                   |
